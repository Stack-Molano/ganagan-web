# Ganagán

## 1. Descripción del proyecto

Ganagán es un proyecto de desarrollo de una plataforma digital orientada a proporcionar herramientas de inteligencia productiva y financiera para pequeños y medianos productores ganaderos.

El proyecto busca integrar información productiva, territorial y económica para facilitar el seguimiento de indicadores, la evaluación de inversiones y la toma de decisiones.

## 2. Objetivo de desarrollo

Construir una plataforma web moderna, intuitiva, adaptable a dispositivos móviles y con una experiencia visual interactiva.

## 3. Tecnologías previstas

- HTML5: estructura de las páginas.
- CSS3: diseño visual, estilos y animaciones.
- JavaScript: interactividad y lógica del cliente.
- FFmpeg: procesamiento y optimización de imágenes y videos.
- Git: control de versiones.
- GitHub: alojamiento del repositorio de código.
- Claude Code: asistencia para el desarrollo e integración del proyecto.

## 4. Estructura del proyecto

- `index.html`: página principal.
- `css/`: hojas de estilos.
- `js/`: funcionalidades e interactividad.
- `assets/images/`: imágenes.
- `assets/videos/`: videos optimizados para la web.
- `assets/icons/`: iconos y elementos gráficos.
- `assets/fonts/`: tipografías.
- `docs/`: documentación técnica.
- `review/`: materiales temporales de revisión.

## 5. Entorno de desarrollo

El proyecto se desarrolla localmente mediante Visual Studio Code y Claude Code.

Git permite registrar los cambios y GitHub conserva el repositorio remoto para facilitar el trabajo desde diferentes computadores.

## 6. Estado del proyecto

Fase inicial: preparación del entorno de desarrollo, organización de archivos y configuración del repositorio.
